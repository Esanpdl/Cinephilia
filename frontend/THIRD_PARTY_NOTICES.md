# Credits and licences

Cinephilia uses the following services and open-source packages.

- [TMDB](https://www.themoviedb.org/) provides film details, artwork URLs and
  trailer metadata. The site credits TMDB in its footer.
- YouTube provides trailer embeds. A player is loaded only when someone chooses
  to watch a trailer.
- [Lucide](https://lucide.dev/) supplies the interface icons.
- [Motion](https://motion.dev/) supplies small interface transitions.
- Oswald and DM Sans are bundled through the Fontsource packages.
- [Be UI Motion](https://beui.dev/components/motion) and the [Criterion
  Channel catalogue](https://films.criterionchannel.com/) informed the visual
  direction of the interface.

The package versions are recorded in `package-lock.json`. The corresponding
licence files remain with the installed packages and are included in the
development archive.
